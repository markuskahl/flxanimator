Systemarchitektur

FlxAnimator basiert auf einer strikten Zwei-Schichten-Architektur (Electron Main Process und isolierter Renderer-Prozess), die maximale Sicherheit, minimale Latenz und saubere Wartbarkeit garantiert:

Wesentliche Architekturmerkmale

  • Reaktiver Vanilla Store: Keine schwergewichtigen State-Libraries (Redux, MobX). Der Store erbt direkt von EventTarget und feuert typisierte CustomEvent-Instanzen.
  • Sicheres Asset-Streaming via app-asset://: Lokale Bilddateien beliebiger Größe werden direkt als Binärstrom ohne Base64-Overhead in den Browser geladen.
  • Undo/Redo mit Deep-Cloning: Beliebige Aktionen (Frames anhängen, löschen, Animationen anlegen, FPS ändern) können verlustfrei rückgängig gemacht und wiederholt werden.

Das von FlxAnimator erzeugte JSON-Format ist vollständig kompatibel zu HaxeFlixel und 2D-Engines:

  "imagePath": "C:/Projects/MyGame/assets/player.png",
  "config": {
    "width": 16,
    "height": 16,
    "spacing": 0,
    "margin": 0
  },
  "animations": [
    {
      "name": "idle",
      "fps": 15,
      "loop": true,
      "flipX": false,
      "flipY": false,

    {
      "name": "walk",
      "fps": 12,
      "loop": true,
      "flipX": false,

HaxeFlixel Code-Integration

Beispiel für die direkte Verwendung in einer FlxSprite-Klasse:

Player.hx 
package entities;

import flixel.FlxSprite;
import haxe.Json;
import openfl.utils.Assets;

class Player extends FlxSprite {
    public function new(X:Float = 0, Y:Float = 0) {
        super(X, Y);
        
        // 1. JSON-Projekt laden & parsen
        var jsonText = Assets.getText("assets/data/player.json");
        var animData = Json.parse(jsonText);
        
        // 2. Grafik mit den exakten Frame-Maßen & Spacing laden
        loadGraphic(
            "assets/images/player.png",
            true,
            animData.config.width,
            animData.config.height,
            false,
            null,
            animData.config.spacing
        );
        
        // 3. Alle Animationssequenzen dynamisch registrieren
        for (anim in (cast animData.animations : Array<Dynamic>)) {
            animation.add(anim.name, anim.frames, anim.fps, anim.loop, anim.flipX, anim.flipY);
        }
        
        // 4. Standard-Animation abspielen
        if (animData.defaultAnimation != null) {
            animation.play(animData.defaultAnimation);
        }
    }
}

Core: Store (State Container)

Der zentrale reaktive Zustandsbehälter für alle Projektdaten, Historien-Snapshots und UI-Zustände.

Typdefinitionen

store.js Types
/**
 * @typedef {Object} SpritesheetConfig
 * @property {number} width - Einzelne Frame-Breite in Pixeln (z. B. 16).
 * @property {number} height - Einzelne Frame-Höhe in Pixeln (z. B. 16).
 * @property {number} spacing - Abstand zwischen Zellen in Pixeln (Standard 0).
 * @property {number} margin - Äußerer Randabstand in Pixeln (Standard 0).
 */

/**
 * @typedef {Object} AnimationData
 * @property {string} name - Name der Animation (z.B. "walk").
 * @property {number} fps - Framerate in Bildern pro Sekunde.
 * @property {boolean} loop - Endloswiedergabe.
 * @property {boolean} flipX - Horizontale Spiegelung.
 * @property {boolean} flipY - Vertikale Spiegelung.
 * @property {number[]} frames - Liste linearer Spritesheet-Frame-Indizes.
 */

Wichtige Methoden

Method setProject(data, filePath = null)

Initialisiert den Store mit einem geladenen oder neu erstellten Projekt, setzt Historien-Stacks zurück und wählt die erste Animation aus.

Feuert: Events.PROJECT_LOADED, Events.ANIMATIONS_CHANGED, Events.ANIMATION_SELECTED

Method toggleFrame(frameIndex)

Schaltet einen Frame in der aktuellen Animation um: Ist er vorhanden, wird er entfernt; andernfalls am Ende angehängt.

Feuert: Events.FRAMES_CHANGED, Events.PROJECT_DIRTY_CHANGED

Method updateConfig(patch, pushHistory = true)

Aktualisiert die Gitterkonfiguration (width, height, spacing, margin) zur Laufzeit. Erzwingt Mindestwerte (Breite/Höhe ≥ 1, Spacing/Margin ≥ 0), markiert das Projekt als geändert und erzeugt optional einen Undo-Snapshot.

Feuert: Events.PROJECT_CONFIG_CHANGED, Events.PROJECT_DIRTY_CHANGED

Method updateSpritesheet(imagePath, imageSrc)

Wechselt die aktive Spritesheet-Bildquelle zur Laufzeit, erzeugt einen Historien-Snapshot für Undo/Redo und informiert alle Canvas- und Vorschau-Komponenten.

Feuert: Events.SPRITESHEET_LOADED, Events.PROJECT_DIRTY_CHANGED

Method undo() / redo()

Macht die vorherige Bearbeitung rückgängig bzw. stellt sie wieder her. Hält maximal 50 Snapshots im Speicher und synchronisiert sowohl Animationen als auch Raster- und Bildzustände.

Feuert: Events.HISTORY_CHANGED, Events.PROJECT_CONFIG_CHANGED, Events.SPRITESHEET_LOADED, Events.ANIMATIONS_CHANGED, Events.FRAMES_CHANGED

Core: grid-utils (Mathematische Hilfsfunktionen)

Reine mathematische Funktionen zur Berechnung von Spritesheet-Gittern, Frame-Koordinaten, Fokus-Zoom und Canvas-Einpassung.

Function calculateGridDimensions(imageWidth, imageHeight, config)

Berechnet Spalten- und Zeilenzahl unter Einbezug von Spacing und Margin:

cols = floor((imageWidth - margin * 2 + spacing) / (width + spacing))

Rückgabe: { cols: number, rows: number, totalCells: number }

Function getFrameCoords(frameIndex, cols, config)

Ermittelt die oberen linken Pixelkoordinaten (x, y) eines linearen Frame-Index.

Rückgabe: { x, y, width, height }

Function calculatePanOnZoom(mouseX, mouseY, oldPanX, oldPanY, oldZoom, newZoom)

Fokus-Zoom Physik: Hält den Punkt unter dem Mauszeiger während des Zoomens exakt an derselben Bildschirmposition.

Rückgabe: { panX: number, panY: number }

UI Komponenten

Alle UI-Komponenten sind modular und lose über das EventTarget des Store gekoppelt:

Component GridCanvasComponent

Steuert das Spritesheet-Bild und das Canvas-Raster-Overlay im Hauptarbeitsbereich. Unterstützt Fokus-Zoom via Mausrad, Canvas-Pan per Drag, Frame-Auswahl per Klick und Drag & Drop von Frames mit virtuellem Ghost-Thumbnail auf die Timeline.

Component PreviewCanvasComponent

Spielt die aktive Animation in Echtzeit auf einem separaten HTML5-Canvas mit konfigurierter Framerate ab. Beachtet FlipX/FlipY Transformations-Matrizen und bietet stufenloses Zoomen und Verschieben.

Component TimelineComponent

Zeigt die Frames der aktuellen Animation als interaktive Kacheln mit nummerierten Badges an. Bietet Hover-Menüs zum sofortigen Duplizieren und Löschen einzelner Frames.

Component SidebarComponent

Verwaltet die Animationsliste sowie den oberen klappbaren Bereich Spritesheet & Grid mit Live-Eingaben für Frame-Breite, -Höhe, Spacing, Margin und Bildwechsel via Dateiauswahldialog. Zeigt zudem dynamische Gitter-Statistiken im Info-Badge an.

Component HeaderComponent & StatusBarComponent

Header: Zeigt Projektname und Dirty-Status * im Fenstertitel an; steuert Neu, Öffnen, Speichern, Speichern unter und öffnet über Settings den Projekteinstellungs-Dialog.
Status Bar: Zeigt kurzzeitige Erfolgs- und Fehlermeldungen mit automatischem 4-Sekunden-Reset an.

Component ProjectSettingsModalComponent

Modaler Dialog (#modal-project-settings) zur Laufzeit-Konfiguration aller Spritesheet- und Raster-Parameter mit Plausibilitätsvalidierung und automatischer Asset-URL-Auflösung.
